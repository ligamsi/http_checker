# Проверка доступности сайтов

## Описание

Программа предназначена для проверки доступности одного или нескольких сайтов. Она выполняет HTTP-запросы к указанным адресам, измеряет время ответа, подсчитывает количество успешных и неуспешных запросов и выводит статистику.

Программа поддерживает:

- получение списка сайтов из командной строки
- чтение сайтов из файла
- сохранение результата в файл
- параллельную проверку сайтов с использованием потоков

## Требования

- Python 3.14+
- requests 2.32.5

## Установка

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

### Проверка сайтов из командной строки

```bash
python bench.py -H https://ya.ru,https://google.com -C 5
```

### Проверка сайтов из файла

Файл hosts.txt:

```text
https://ya.ru
https://google.com
```

Запуск:

```bash
python bench.py -F hosts.txt -C 3
```

### Сохранение результата в файл

```bash
python bench.py -H https://ya.ru -C 5 -O result.txt
```

## Аргументы командной строки

* -H, --hosts - Список сайтов через запятую
* -F, --file - Файл со списком сайтов
* -C, --count - Количество запросов
* -O, --output - Файл для сохранения результата
